# Phase 08 — Ordered calendar observations

Status: implementation under test. HyperFlow owns Google calendar credentials, calendar grants, proposals, booking and provider reconciliation. Communications continues to own normalized event context and participant enrichment. No booking endpoint or memory extraction is introduced.

Migration 023 serializes updates to one tenant/provider event and rejects stale or unversioned replacements of timestamped observations. Event and participant snapshots remain atomic. Exact normalized email identities enrich participants; cross-tenant contact/project/thread references are rejected. Cancelled observations no longer generate automatic meeting candidates. The public endpoint remains POST /v1/calendar/events.

The database fixture verifies correction, stale replay, participant removal, normalized contact matching and cancelled candidate exclusion. Deployment and real provider acceptance are not yet claimed.
